## Findings considered and rejected

- **CORRECTNESS-02** (Promise.all fail-fast): By design for a CLI tool with bounded lifetime. Addressed partially in Plan 007 as defense-in-depth.
- **CORRECTNESS-05** (negative step loop): Guarded by validation; only a risk if validation is removed.
- **CORRECTNESS-07** (NDJSON circular data): `JSON.parse` never produces circular references — cannot happen.
- **CORRECTNESS-09** (file write race): Guarded by CLI mutual exclusion of output formats.
- **PERF-2, 5, 6, 7** (micro-optimizations): Measurable only at unrealistic scales; not worth plans.
- **DEP-1 through DEP-7** (dependency issues): All transitive dev-deps or RC pins with zero runtime impact. DEP-4 (npm audit broken) is addressed in Plan 001.
- **ARCH-01** (serializeDeps homogeneous): Intentional future-proofing with zero cost; removing adds churn.
- **ARCH-03** (ExtractionStrategy functor): 19 lines for 2 implementations is not plan-worthy overhead.
- **TC-08, TC-09, TC-10** (minor test quality): Low leverage, not worth dedicated plans.
- **DOCS-01 through DOCS-05** (minor doc nits): Low leverage compared to DOCS-06 (copilot-instructions, addressed in Plan 001).
- **DefaultsMerger full consolidation**: Originally estimated 234→40 lines, but ReScript's record types require per-field `pickOption` — a generic merge would need unsafe casts. Plan 012 is reduced to cosmetic cleanup (~50 lines removed) rather than the full consolidation. Full consolidation would require ppx metaprogramming.
- **DIRECTION-01 through DIRECTION-08**: Direction findings (plugin strategies, library mode, proxy docs, streaming cap) are design/spike plans, not execution plans. Deferred to the maintainer's roadmap.
